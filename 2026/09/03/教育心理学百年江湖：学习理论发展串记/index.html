教育心理学百年江湖：学习理论发展串记

Luvicii2026-09-032026-09-03

第一章：一切从一只饿猫开始（1898年）

1898年，哥伦比亚大学的实验室里，桑代克把一只饿了好几顿的猫关进一个特制的木笼——后人叫它”迷笼”。笼外放着香喷喷的鱼。那只猫在笼子里乱抓乱咬，上蹿下跳，偶然间碰到了一个机关，门开了，猫冲出去吃到了鱼。桑代克一次又一次把它关回去，猫每次都要折腾一阵子，但开门的时间越来越短。

桑代克看着记录本，得出一个结论：学习就是试误。猫不是”想明白”了怎么开门，而是在刺激（关在笼子里）和反应（碰机关）之间，慢慢建立了一条联结。他总结出三条定律：准备律、练习律、效果律。尤其是效果律——结果满意，联结就加强；结果烦恼，联结就减弱。

后来桑代克还提出了共同要素说，指出学习迁移的关键是新旧情境中有共同成分，为后来的学习迁移理论埋下了种子。

这是人类历史上第一次用严格的实验来研究”学习”这件事。桑代克成了开山祖师，但他自己可能也没想到，他点燃的这把火，会烧出接下来一百年的江湖恩怨。

记忆锚点：猫 = 试误；效果律 = “满意就加强，烦恼就减弱”

第二章：俄国佬的意外发现（1900年代）

就在桑代克研究猫的时候，千里之外的俄国，生理学家巴甫洛夫正在研究狗的消化。他本来跟”学习”八竿子打不着，但他在实验里发现了一个怪事：狗不仅在看到食物时流口水，听到饲养员的脚步声、甚至实验室的铃声，也开始流口水。

巴甫洛夫敏锐地抓住了这个”意外”。他设计了一个精巧的实验：每次给狗食物之前，先摇铃。反复多次后，只摇铃不给食物，狗照样流口水。他把这叫做经典条件作用——原本中性的铃声，因为和食物反复”配对”，变成了能引发反应的条件刺激。

他还发现了一系列规律：如果总是只摇铃不给食物，流口水会慢慢消失，这叫消退；如果听到类似的声音也流口水，这叫泛化；如果能分辨出只有特定铃声才给食物，这叫分化。

巴甫洛夫是个生理学家，但他的发现成了后来整个行为主义门派的”内功心法”。他还研究了高级神经活动类型（兴奋/抑制过程的强度、平衡性、灵活性），后来成了气质类型（胆汁质、多血质、黏液质、抑郁质）的生理学基础。

记忆锚点：狗 = 经典条件作用；S-R联结，被动反应

第三章：华生的野心（1913年）

1913年，美国心理学家华生站了出来。他看着桑代克和巴甫洛夫的成果，觉得心理学界那些研究”意识””感觉””心灵”的人都是在瞎搞。他发表了一篇檄文，宣告：心理学应该只研究可观察的行为，什么意识、什么心灵，统统赶出去！

这就是行为主义的正式诞生。

华生把巴甫洛夫的经典条件作用从狗身上搬到了人身上。他做了一个后来臭名昭著但也名垂青史的实验：让一个婴儿（小阿尔伯特）原本很喜欢小白鼠，但每次鼠出现时都伴随巨大的噪音，最后婴儿一见到小白鼠就哭，甚至见到毛茸茸的东西都害怕。华生得意地说：”给我一打健康的婴儿，我可以把他们培养成任何人——医生、律师、艺术家，甚至是乞丐或盗贼。”

在华生眼里，人就是一台机器，输入什么刺激，就输出什么反应。环境决定一切。这个思想在当时的美国掀起了巨浪，行为主义帝国正式建立。

记忆锚点：华生 = 行为主义宣言；小阿尔伯特 = 情绪条件化

第四章：德国人的反击（1920年代）

华生的行为主义在美国如日中天，但大洋彼岸的德国人看不下去了。

1920年代，德国心理学家苛勒带着一群”格式塔学派”的人，在加那利群岛的实验室里，把黑猩猩关进笼子，笼顶挂着香蕉，地上放着几个木箱。黑猩猩一开始也跳、也抓，但突然——真的是突然——它停下来了，环顾四周，然后把箱子叠在一起，站上去，拿到了香蕉。

苛勒激动地记录：这不是试误！黑猩猩不是像桑代克的猫那样盲目乱撞，而是顿悟了！它理解了箱子、高度、香蕉之间的关系，在脑子里形成了一个新的”完形”（整体结构）。

格式塔学派向行为主义发出了第一记重拳：学习不是刺激-反应的联结，而是对情境整体结构的突然理解。整体大于部分之和。

桑代克的猫和苛勒的猩猩，成了这场论战的两面旗帜。

记忆锚点：猩猩 = 顿悟；完形 = 整体大于部分之和

第五章：行为主义内部的”叛徒”（1930年代）

1930年代，行为主义的大本营里，出现了一个”叛徒”——托尔曼。

托尔曼表面上还在用行为主义那套方法：迷宫、老鼠、食物。但他做了一个让斯金纳之流坐立不安的实验。他让老鼠在迷宫里跑，但分成了三组：一组每次跑到终点都有食物（有奖励），一组从来没有食物（无奖励），还有一组前10天没食物，第11天突然给食物。

结果惊人：前10天没食物的老鼠，虽然看起来跑得很懒散，但第11天一旦给食物，它们的表现瞬间追上了一直有奖励的老鼠。托尔曼说：学习一直在发生，只是没有表现出来！ 老鼠的脑子里有一张认知地图，它们一直在默默构建对迷宫的理解。

这叫潜伏学习。托尔曼用行为主义的工具，证明了认知主义的思想。他像是一个潜伏在敌营里的间谍，从内部动摇了”没有强化就没有学习”的教条。

记忆锚点：老鼠 = 潜伏学习；认知地图 = 学习可以”隐形”

第六章：斯金纳的机械帝国（1930s-1950s）

几乎在同一时间，另一个年轻人斯金纳走上了另一条路。他嫌桑代克和华生太”软”，决定用更精密的方式控制行为。

他发明了一个箱子——斯金纳箱。箱子里有一只饥饿的白鼠，箱壁有一个杠杆，一按就掉食物丸。白鼠偶然碰到杠杆，吃到了食物，然后它按杠杆的频率越来越高。如果按了不再掉食物，按杠杆的行为就会慢慢消失——这叫消退。

斯金纳把行为分成两类：由刺激引发的应答性行为（巴甫洛夫的狗），和自发产生的操作性行为（他的老鼠）。人类绝大多数学习都是操作性的。而控制操作性行为的钥匙，是强化。

他把这个体系推向了极致：

  • 正强化：给奖励（发食物丸）
  • 负强化：撤销厌恶刺激（如”停止批评””免除额外惩罚”）
  • 正惩罚：给厌恶刺激（批评）
  • 负惩罚：撤销愉快刺激（没收手机）

他还研究了强化程式：是每次都给奖励，还是随机给？固定时间给还是变时间给？他发现，老虎机那种可变比率强化，能让人上瘾到疯狂。

斯金纳相信，人的行为完全可以像机器一样被设计和控制。他甚至把这套理论搬进了教室，发明了程序教学：把知识切成小碎块，学生每完成一步立刻得到反馈，像训练老鼠一样训练学生。

行为主义在斯金纳手里达到了巅峰，也走到了让人不安的极端。

记忆锚点：老鼠 = 操作条件作用；正/负强化 = “给好处”vs”撤痛苦”；程序教学 = 小步子+即时反馈

第七章：人本主义的”造反”（1940s-1960s）

斯金纳把人当机器，终于有人忍不了了。

1940年代，一个曾经研究行为主义的心理学家马斯洛，突然”叛逃”了。他说：人不是老鼠！人有尊严，有情感，有追求！他提出了著名的需求层次金字塔：生理需求、安全需求、归属与爱的需求、尊重需求，最顶端是自我实现——充分发挥个人潜能，成为你能成为的样子。

马斯洛研究了爱因斯坦、罗斯福、林肯这些人，发现自我实现者有一种高峰体验：极度兴奋、极度满足、与世界融为一体的瞬间。学习，应该是通向自我实现的路，而不是按杠杆取食丸。

与此同时，心理咨询师罗杰斯也加入了这场”造反”。他本来在诊所里用”来访者中心疗法”帮人解决心理问题，后来他把这套理念搬进了教室。他说，学习分两种：一种是”颈部以上”的无意义学习，只涉及记忆和心智；另一种是有意义学习，涉及整个人的情感、态度、个性。

罗杰斯提出了一个在当时石破天惊的观点：教师的角色不是传授知识，而是”学习的促进者”。 只要满足三个条件——真诚、无条件积极关注、同理心——学生自己就会生长。他甚至倡导非指导性教学：老师不讲课，只提供资源，学生自己决定学什么、怎么学、怎么评价自己。

马斯洛和罗杰斯联手，创立了人本主义心理学，被称为心理学界的”第三势力”。他们站在斯金纳的对立面，喊出了时代的最强音：教育的目的不是塑造行为，而是培养完整的人。

记忆锚点：马斯洛 = 需求层次+自我实现；罗杰斯 = 促进者+非指导性教学

第八章：认知主义的正式登场（1950s-1960s）

人本主义在情感上震撼了教育界，但在认知机制上，还需要更精密的理论。这时候，认知主义正式接过了大旗。

瑞士心理学家皮亚杰其实从1920年代起就开始默默研究儿童了。他把自己的孩子当”实验对象”，观察他们怎么认识世界。到了1950年代，他的思想终于在英语世界掀起风暴。他提出了震惊世人的认知发展阶段论：0-2岁是感知运动阶段，靠动作认识世界；2-7岁是前运算阶段，开始用符号但思维不可逆；7-11岁是具体运算阶段，能逻辑推理但需要具体事物支撑；11岁以后进入形式运算阶段，能进行抽象假设和演绎推理。

皮亚杰说，小孩不是被动接收知识的小瓶子，而是主动探索世界的”小科学家”。他们通过同化（把新经验塞进已有的认知框架）和顺应（调整框架以适应新经验），不断建构对世界的理解。

皮亚杰的思想像一颗种子，后来长成了两棵大树：一棵是认知主义，一棵是建构主义。

记忆锚点：皮亚杰 = 阶段论+同化顺应；儿童 = 小科学家

第九章：布鲁纳与奥苏贝尔的”欢喜冤家”（1960s）

1960年代，皮亚杰的思想传到了美国，催生了两位大将，但他们一见面就吵架。

第一位是布鲁纳。他高举”发现学习“的大旗，说学习的实质是主动形成认知结构，教学的目的是让学生掌握学科的基本结构——那些最基本的概念、原理、方法。他主张让学生像科学家一样，自己去探索、去发现，而不是听老师灌输。他还提出，人的认知表征经历三个阶段：小时候靠动作（动作性表征），后来靠图像（映象性表征），最后靠语言和符号（符号性表征）。

第二位是奥苏贝尔。他听了布鲁纳的演讲，皱着眉头站起来说：”发现学习是好，但学校教学的主流应该是有意义的接受学习！”他说，只要新知识和学生脑子里的旧知识建立了实质性的、非人为的联系，老师讲、学生听，完全也可以是有意义的。他还发明了一个教学神器——先行组织者：在讲新知识之前，先抛出一个概括性更强的大概念，帮学生搭一座桥，让新旧知识连起来。

布鲁纳和奥苏贝尔争论了一辈子。一个说”要自己发现”，一个说”接受也行，关键是理解”。但他们其实是一枚硬币的两面：都强调认知结构，都反对机械记忆。

记忆锚点：布鲁纳 = 发现学习+学科结构+三种表征；奥苏贝尔 = 有意义接受学习+先行组织者

第十章：班杜拉的”中间路线”（1960s-1970s）

就在行为主义和认知主义打得火热的时候，班杜拉走出了一条中间路线。

1961年，他在斯坦福大学做了一个实验。他让一群孩子看一段影片：一个成年人在殴打一个充气”波波玩偶”，有的版本里打人者受到了表扬，有的受到了批评，有的没有后果。然后他把孩子们带进一个有波波玩偶的房间。结果，看到打人者受表扬的孩子，攻击行为最多；看到受批评的，攻击行为最少。

班杜拉说：学习不一定需要亲自尝试，也不需要直接受到强化。 孩子通过观察榜样的行为及其后果，就学会了新行为。这叫观察学习，也叫替代学习。

他还提出了三元交互决定论：环境、行为、个体的认知，三者相互影响，不是你决定我、我决定你那么简单。

到了1977年，班杜拉又抛出了另一枚重磅炸弹——自我效能感：你相不相信自己能做成一件事，比你能不能做更重要。

班杜拉像一座桥，把行为主义的环境因素和认知主义的信念因素，巧妙地连接在了一起。

记忆锚点：波波玩偶 = 观察学习；三元交互 = 环境×行为×认知；自我效能 = “我相信我能”

第十一章：加涅的”缝合术”（1960s-1970s）

到了1960年代末，江湖上已经门派林立：行为主义、认知主义、人本主义各执一词。这时候，一个名叫加涅的人站了出来，他想：为什么不能把它们缝合在一起？

加涅把大脑比作一台计算机，提出了信息加工学习理论。外界刺激进入感受器，经过感觉登记（瞬时记忆），进入短时记忆（工作记忆），再编码进入长时记忆。需要的时候，从长时记忆里提取出来，通过反应发生器变成行为。这就是记忆的三级存储模型。

他还把学习过程细分为八个阶段：动机→领会→习得→保持→回忆→概括→作业→反馈。对应这八个阶段，教师应该设计九大教学事件：引起注意、告知目标、刺激回忆先前知识、呈现材料、提供指导、诱发行为、提供反馈、评价表现、促进记忆与迁移。

加涅像一个系统工程师，把各家各派的碎片组装成了一套完整的教学设计操作系统。

记忆锚点：加涅 = 信息加工+八阶段+九事件；大脑 = 计算机

第十二章：建构主义的革命（1970s-1990s）

认知主义发展到极致，一场更大的革命正在酝酿。

皮亚杰早就说过，知识不是客观世界的镜像，而是个体主动建构的。但他的思想在1970年代被推向了新的高度，形成了建构主义。

建构主义内部有两条脉络：

一条来自皮亚杰本人，强调个体与物理环境的互动，知识是个体自己建构的。这叫认知建构主义/个人建构主义。

另一条来自苏联心理学家维果茨基。他在1930年代就提出了完全不同的视角（可惜英年早逝，思想被尘封多年，直到1970年代才被西方重新发现）：知识是在社会交往中建构的。他提出了著名的最近发展区——儿童独立解决问题的水平，和在成人指导下能达到的水平，中间有一段差距，这就是教学应该瞄准的区域。他还提出了支架的概念：老师像搭脚手架一样，提供暂时性的支持，帮学生完成独自做不到的事，然后逐步撤掉。

皮亚杰和维果茨基，一个说”个体建构”，一个说”社会建构”。两人从未见面，但思想完美互补。

到了1980-1990年代，现代建构主义者把两者融合，提出了一系列教学模式：

  • 支架式教学（来自维果茨基）
  • 抛锚式教学（把知识锚定在真实问题情境中）
  • 随机通达教学（复杂知识要从多个角度反复学习）
  • 认知学徒制（像师傅带徒弟一样学思考）

建构主义向整个教育界宣告：知识不是客观真理，而是情境中的解释；学生不是空着脑袋进教室的，他们带着丰富的经验；教师的任务不是传递知识，而是促进学生在自己的经验基础上建构意义。

记忆锚点：皮亚杰 = 个体建构；维果茨基 = 社会建构+最近发展区+支架
